# Glossary of Abbreviations

This glossary defines all abbreviations used in the Menial AI project, particularly in the training notebook and related code.

---

## Symbols & Numbers

- **2D** - Two-Dimensional

## A

- **A100** - NVIDIA A100 (GPU model)
- **Adam** - Adaptive Moment Estimation (optimizer algorithm)
- **AdamW** - Adam with Weight Decay
- **AMP** - Automatic Mixed Precision
- **API** - Application Programming Interface
- **AST** - Audio Spectrogram Transformer
- **AudioSet** - Google's large-scale audio dataset (2M+ YouTube clips, 521 classes)

## B

- **BatchNorm** - Batch Normalization (neural network layer that normalizes activations)

## C

- **C++** - C plus plus (programming language)
- **CD** - Compact Disc
- **CNN** - Convolutional Neural Network
- **Conv2d** - 2D Convolution (convolutional layer for 2D data)
- **CPU** - Central Processing Unit
- **CSV** - Comma-Separated Values
- **CUDA** - Compute Unified Device Architecture (NVIDIA's parallel computing platform)
- **cuDNN** - CUDA Deep Neural Network library

## D

- **dB** - Decibels (unit of sound intensity)

## E

- **e.g.** - exempli gratia (Latin: "for example")
- **ESC-50** - Environmental Sound Classification - 50 categories (audio dataset)
- **etc.** - et cetera (Latin: "and so forth")

## F

- **F1** - F1 Score (harmonic mean of precision and recall)
- **FFT** - Fast Fourier Transform

## G

- **GPU** - Graphics Processing Unit

## H

- **Hz** - Hertz (unit of frequency)

## I

- **i.e.** - id est (Latin: "that is")
- **ID** - Identifier
- **inf** - infinity (mathematical concept; infinite value)
- **ISTFT** - Inverse Short-Time Fourier Transform

## J

- **JSON** - JavaScript Object Notation

## K

- **KB** - Kilobytes

## L

- **L2** - L2 norm/regularization (method for preventing overfitting)
- **LLM** - Large Language Model
- **LR** - Learning Rate

## M

- **matplotlib** - Python plotting library (Mathematical Plotting Library)
- **MaxPool** - Max Pooling (downsampling operation that selects maximum values)
- **MB** - Megabytes
- **MFCC** - Mel-Frequency Cepstral Coefficients
- **ms** - milliseconds

## N

- **NaN** - Not a Number (indicates an undefined or unrepresentable numerical result)
- **NLL** - Negative Log-Likelihood
- **NMF** - Non-Negative Matrix Factorization
- **numpy** - Numerical Python (scientific computing library)

## O

- **ONNX** - Open Neural Network Exchange

## P

- **pandas** - Python Data Analysis Library (data manipulation library)
- **PANNs** - Pretrained Audio Neural Networks
- **pt** - PyTorch (file extension)
- **PyTorch** - Python-based deep learning framework

## R

- **ReLU** - Rectified Linear Unit (activation function)
- **ResNet** - Residual Network (deep neural network architecture with skip connections)
- **RGB** - Red Green Blue (color channels)
- **RMSprop** - Root Mean Square Propagation (optimization algorithm)
- **RNG** - Random Number Generator

## S

- **scikit-learn** - Python machine learning library (also imported as **sklearn**)
- **scipy** - Scientific Python (library for scientific computing)
- **SGD** - Stochastic Gradient Descent
- **sklearn** - scikit-learn (common import alias)
- **SpecAugment** - Spectrogram Augmentation (data augmentation technique for audio)
- **STFT** - Short-Time Fourier Transform

## T

- **T4** - NVIDIA Tesla T4 (GPU model)
- **TensorFlow** - Google's open-source machine learning framework

## V

- **VM** - Virtual Machine
- **vs.** - versus (Latin: "against" or "compared to")

## W

- **wav** - Waveform Audio File Format

## Y

- **YAMNet** - Yet Another Mobile Network (Google's audio classification model trained on AudioSet)

## Z

- **ZCR** - Zero-Crossing Rate

---

*This glossary covers abbreviations from audio signal processing, machine learning, computing hardware, data formats, libraries, Latin phrases, and general technical terms used throughout the project.*
